# Related papers and public code

The following representative detectors are cited as related detection methods. The table gives a short description of each method and links to its corresponding public implementation.

| Baseline | Main idea | Reference paper / public code |
|---|---|---|
| **RT-DETR** | Real-time end-to-end DETR detector with an efficient hybrid encoder and query-based prediction; NMS-free inference. | [RT-DETR repository](https://github.com/lyuwenyu/RT-DETR) |
| **DINO** | DETR variant with denoising training, improved query selection, and contrastive query design for stronger object-query learning. | [DINO repository](https://github.com/IDEA-Research/DINO) |
| **D-FINE** | Fine-grained distribution refinement for bounding-box regression, targeting more accurate localization with an efficient end-to-end pipeline. | [D-FINE repository](https://github.com/Peterande/D-FINE) |
| **Wafer-YOLO** | Lightweight wafer-inspection detector using structural-prior guidance and task-oriented feature processing. | [Wafer-YOLO paper and code](https://github.com/xiez-njust-xmu/Wafer-YOLO) |
| **Ultralytics YOLO** | Standard one-stage YOLO framework with unified training, validation, prediction, and model-export interfaces. | [Ultralytics repository](https://github.com/ultralytics/ultralytics) |

WaferLO is the task-specific model implemented in this repository. The implementations, papers, and checkpoints of these referenced methods remain maintained by their original authors and are not copied into this project.
